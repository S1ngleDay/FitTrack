# FitTrack

FitTrack — мобильное приложение для отслеживания тренировок, статистики, маршрутов и планов занятий. Проект создан на React Native с использованием Expo и предназначен для удобного ведения активности, анализа прогресса и управления тренировочным процессом.

## Возможности

- Учет тренировок и создание тренировок вручную
- Статистика по шагам, калориям, расстоянию и времени
- Графики активности и сводные экраны
- Отслеживание маршрута и геолокации для пробежек и активностей на улице
- Управление тренировками и планами занятий
- Настройки и параметры пользователя
- Поддержка уведомлений и фонового отслеживания
- Локальное хранение данных в приложении

## Технологии

- React Native + Expo
- React Navigation
- Zustand для управления состоянием
- AsyncStorage для хранения данных
- Expo Location / sensors / notifications
- Reanimated и графики для аналитических экранов

## Требования

Перед запуском приложения убедитесь, что у вас установлено:

- Node.js 18+
- npm или yarn
- Expo CLI
- Android Studio или Xcode для запуска эмулятора/устройства
- iPhone, Android-устройство или браузер для веб-предпросмотра

## Быстрый старт

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите Expo-сервер:

   ```bash
   npm start
   ```

3. Запустите приложение на целевой платформе:

   ```bash
   npm run android
   ```

   или

   ```bash
   npm run ios
   ```

   или для веб:

   ```bash
   npm run web
   ```

## Основные части приложения

- `src/screens` — основные экраны: главная, тренировки, статистика, настройки и итоговые представления
- `src/components` — переиспользуемые UI-компоненты и карточки
- `src/store` — логика хранилищ состояния и данные приложения
- `src/hooks` — пользовательские хуки для расчётов и отслеживания активности
- `src/utils` — вспомогательные утилиты для статистики, маршрутов, уведомлений и резервных копий
- `src/navigation` — навигация и структура вкладок приложения

## Типичный сценарий использования

- Открыть приложение и создать или просмотреть тренировку
- Начать отслеживание активности из режима активной тренировки
- Просматривать статистику и графики прогресса
- Управлять планами тренировок и настройками пользователя

## Примечания

- Проект рассчитан на мобильное приложение для фитнес-учета и оптимизирован под локальную разработку через Expo.
- Некоторые функции зависят от разрешений устройства: геолокация, уведомления и датчики движения.
- Репозиторий организован в логическую структуру с разделением экранов, хранилищ и утилит по ответственности.
